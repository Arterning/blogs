# 磁盘与存储

## 查看磁盘与容量

```cmd
wmic logicaldisk get name,size,freespace   :: 各盘符容量（字节）
fsutil volume diskfree c:                  :: 指定盘剩余空间
```

PowerShell 等价（推荐）

```powershell
Get-PSDrive -PSProvider FileSystem                  # 各盘容量
Get-Volume                                          # 卷信息
Get-Disk                                            # 物理磁盘
Get-Partition                                       # 分区
```

## 磁盘与分区管理（diskpart，管理员）

```cmd
diskpart                :: 进入交互式会话
```

交互式常用操作：

```text
list disk               // 列出磁盘
select disk 1           // 选择磁盘
list partition          // 查看分区
clean                   // 清空磁盘 ⚠️ 全部数据丢失
create partition primary size=102400   // 创建 100GB 主分区
format fs=ntfs quick   // 快速格式化为 NTFS ⚠️ 清空该分区
assign letter=E         // 分配盘符
```

> ⚠️ `clean` / `format` 会丢失数据，操作前务必确认 `select disk` 选对了磁盘。

## chkdsk 检查修复（管理员）

```cmd
chkdsk c:               :: 检查 C 盘
chkdsk c: /f            :: 检查并修复错误（可能需要重启）
chkdsk c: /f /r         :: 修复并扫描坏扇区（很慢）
chkdsk /scan            :: 在线扫描（不锁定磁盘）
```

## 磁盘清理与优化

```cmd
cleanmgr                :: 打开磁盘清理（图形界面）
cleanmgr /d C: /sagerun:1   :: 静默执行预配置的清理方案（需先 /sageset:1 配置）
defrag c:               :: 磁盘碎片整理（机械盘）
defrag c: /u /v         :: 查看整理详情
defrag c: -h            :: 快速模式（SSD 一般无需整理）
```

```powershell
Optimize-Volume -DriveLetter C -ReTrim -Verbose    # SSD 使用 ReTrim 回收
```

## 压缩卷 / 扩展卷

```cmd
# CMD 难以直接操作，图形界面路径：
# 此电脑 → 右键 → 管理 → 磁盘管理 (diskmgmt.msc)
# 也可用 PowerShell
Resize-Partition -DriveLetter C -Size 200GB     # 扩展到 200GB（需有未分配空间）
```

## 移动/迁移数据

```cmd
robocopy "C:\Users\me\Documents" "D:\backup" /E /R:1 /W:1 /COPY:DAT   :: 备份资料
mklink /J D:\link "C:\真实目录"     :: 创建目录联接（把大目录搬到其他盘后原地留链接）
```

## 文件占用排查

```cmd
# 查看某个文件/目录被哪个进程占用
openfiles /query        :: 需先开启全局打开文件列表（需要管理员）
# 常用方案：使用进程资源管理器（Sysinternals 的 Process Explorer）
#   opendumps / handle64.exe file.exe "路径"    查找占用句柄
# 简单方案：PowerShell + Sysinternals handle
```

## 常见场景速查

| 场景 | 命令 |
| --- | --- |
| 磁盘满了找大文件 | PowerShell: `Get-ChildItem D:\ -Recurse -File \| Sort-Object Length -Descending \| Select -First 20` |
| 清理垃圾 | `cleanmgr` + 回收站/临时目录 `%TEMP%` |
| 检查坏道 | `chkdsk c: /r`（时间长） |
| 移动大目录 | `robocopy 源 目标 /E /MOVE` ⚠️ 源会被删除 |
| 制作启动盘 | 用 Rufus / `dism` 写镜像（见维护篇） |
