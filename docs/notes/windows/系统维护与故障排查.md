# 系统维护与故障排查

## 系统文件修复（核心三连）

```cmd
sfc /scannow                :: 扫描并修复系统文件（可能需重启）常用第一步
dism /online /cleanup-image /restorehealth   :: 修复系统映像（DISM 源）第二步
```

顺序：先 `sfc /scannow`，若修复失败/反复，再 `dism`（从 Windows Update 拉取原文件），然后重启再跑一遍 `sfc`。

DISM 也常用离线修复：

```cmd
dism /online /cleanup-image /startcomponentcleanup       :: 清理组件存储(WinSxS)
dism /online /get-imageinfo  /imagefile:D:\install.wim   :: 查看镜像信息
dism /mount-wim /wimfile:D:\install.wim /index:1 /mountdir:C:\mnt   :: 挂载镜像编辑
```

## chkdsk 磁盘检查

```cmd
chkdsk c: /f /r            :: 检查并修复 + 扫描坏扇区（可能需要计划重启）
```

> C 盘被占用时提示「是否计划下次重启检查」，输入 Y 重启即可。

## 安全模式与启动修复

```cmd
bcdedit                      :: 查看启动配置
bcdedit /enum                :: 展示全部启动项
msconfig                     :: 引导 → 安全引导勾选（进安全模式）
shutdown /r /o /t 0          :: 重启到「高级启动选项」（疑难解答→启动设置→安全模式）
```

启动修复 GUI：设置 → 系统 → 恢复 → 高级启动 → 疑难解答。

## 注册表管理

```cmd
regedit                      :: 图形编辑注册表
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v ProductName
reg add "HKCU\Control Panel\Desktop" /v Wallpaper /t REG_SZ /d "D:\img.jpg" /f
reg delete "HKLM\SOFTWARE\Demo" /f
reg export "HKLM\SOFTWARE\Demo" demo.reg      :: 导出备份
reg import demo.reg          :: 导入
```

PowerShell：

```powershell
Get-ItemProperty "HKCU:\Control Panel\Desktop"
Set-ItemProperty "HKCU:\Control Panel\Desktop" -Name Wallpaper -Value "D:\img.jpg"
New-Item "HKCU:\Software\Demo" -Force
Remove-Item "HKCU:\Software\Demo" -Recurse
```

> ⚠️ 改注册表前建议先 `reg export` 备份；误删可导致系统异常。

## 用户与权限

```cmd
net user                     :: 列出本地用户
net user newuser pass /add   :: 添加用户
net localgroup administrators newuser /add   :: 加入管理员组
net user olduser /delete     :: 删除用户（管理员）
whoami /groups | findstr S-1-5-32-544     :: 检查是否管理员组
runas /user:管理员 程序      :: 以其他用户运行
```

PowerShell：

```powershell
Get-LocalUser / New-LocalUser / Remove-LocalUser
Get-LocalGroupMember -Group "Administrators"
Add-LocalGroupMember -Group "Administrators" -Member "newuser"
```

## 日志查看

```cmd
eventvwr                     :: 事件查看器 GUI
wevtutil qe System /c:20 /rd:true /f:text    :: 最近的系统日志 20 条
wevtutil el                   :: 列出所有日志通道
```

看关键错误：

```powershell
Get-WinEvent -FilterHashtable @{LogName='System'; Level=2; StartTime=(Get-Date).AddHours(-24)} | Select -First 20
Get-WinEvent -FilterHashtable @{LogName='Application'; Level=2} | Select -First 10
```

## 内存转储与蓝屏分析

```cmd
C:\Windows\Minidump           :: 小内存转储位置
C:\Windows\MEMORY.DMP         :: 完整转储
verifier                      :: 驱动验证器（排查驱动导致的蓝屏 ⚠️ 高级）
```

分析蓝屏 dump 常用工具：WinDbg（Windows SDK）、BlueScreenView。

## 网络重置（管理员）

```cmd
netsh winsock reset          :: 重置 Winsock 目录
netsh int ip reset           :: 重置 IP 协议栈
ipconfig /flushdns           :: 刷新 DNS
:: 通常需要重启生效，解决「无法上网但网络图标正常」问题
```

## 重装与修复工具

```cmd
DISM 做备用系统镜像：
dism /Capture-Image /ImageFile:D:\win.wim /CaptureDir:C:\ /Name:"system"
:: 或用官方 Media Creation Tool 制作 USB 启动盘修复/重装
```

## 快捷键排查

| 问题 | 入口 |
| --- | --- |
| 任务管理器打不开 | `taskmgr` 或 Ctrl+Shift+Esc |
| 服务启动不了 | `services.msc` + 事件查看器 |
| 磁盘占用 100% | `resmon` → 磁盘；`osd` 进程索引停用 |
| 系统卡顿 | `perfmon` 计数或任务管理器「性能」 |
| 开机慢 | 任务管理器 → 启动项禁用心智 |
