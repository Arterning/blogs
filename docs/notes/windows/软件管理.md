# 软件管理

## winget（Win10/11 自带包管理器，推荐）

```cmd
winget list                          :: 已安装软件清单
winget search nginx                  :: 搜索软件
winget show nginx                    :: 查看软件信息与源
winget install nginx                 :: 安装
winget install -e --id Git.Git      :: 按 id 精确安装
winget upgrade --all                :: 升级全部
winget upgrade nginx                 :: 升级单个
winget uninstall nginx               :: 卸载
winget export -o apps.json          :: 导出已装清单（迁移系统用）
winget import -i apps.json          :: 批量导入安装
winget --disable-interactivity      :: 静默安装（脚本用）
```

常用参数：`-e` 精确匹配 ID，`-s winget` 指定源，`--accept-package-agreements --accept-source-agreements` 免确认，`-h` 静默。

## Chocolatey（老牌包管理器）

```cmd
choco install git -y                 :: 安装
choco upgrade all -y                 :: 升级全部
choco search nginx                   :: 搜索
choco uninstall git -y               :: 卸载
choco list                           :: 列出已装
```

需要管理员权限；常用软件名：`git`、`nodejs-lts`、`python`、`docker-desktop`、`googlechrome`、`7zip`、`jq`。

## Scoop（Windows 版 brew，免管理员）

```cmd
scoop install git curl jq            :: 一次装多个（用户目录安装，不污染系统）
scoop update *                       :: 升级全部
scoop search nginx
scoop uninstall jq
scoop bucket add extras              :: 添加扩展软件源
```

适用于命令行/开发工具，装图形软件用 `extras` bucket。

## MSI / EXE 静默安装

```cmd
msiexec /i package.msi /qn /norestart             :: 静默安装 MSI
msiexec /i package.msi /qn TRANSFORMS=config.mst  :: 带参数安装
msiexec /x package.msi /qn                        :: 静默卸载
start /wait setup.exe /S                         :: EXE 静默安装（多数支持 /S）
```

常见 EXE 静默参数：`/S`（InstallShield/Nsis）、`/quiet`、`/verysilent`（Inno）。

## 系统应用（Appx / UWP）

```powershell
Get-AppxPackage | Select-Object Name, Version, InstallLocation        # 列出应用商店应用
Get-AppxPackage -Name *photos* | Remove-AppxPackage                 # 卸载预装（⚠️ 谨慎）
Add-AppxPackage -Register "C:\Program Files\WindowsApps\xxx\AppxManifest.xml"
```

## 驱动管理（pnputil）

```cmd
pnputil /enum-drivers                :: 列出全部驱动包
pnputil /add-driver driver.inf /install   :: 安装驱动
pnputil /delete-driver oem0.inf     :: 删除驱动包
pnputil /scan-devices               :: 扫描新硬件
```

## 卸载残留处理

```cmd
控制面板 → 程序和功能          :: 常规卸载入口（appwiz.cpl）
%ProgramData%\Microsoft\Windows\Start Menu\Programs   :: 开始菜单快捷方式
reg query "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall"
                                   :: 查看注册表卸载项（可查 GUID 卸载）
```

winget install -e --id OpenJS.NodeJS.LTS
