系统信息与硬件

系统基本信息​

systeminfo               :: 版本、补丁、内存、网卡汇总（信息量大）
ver                      :: Windows 版本号
hostname                 :: 主机名
whoami                   :: 当前用户名与域
whoami /priv             :: 当前用户的权限列表

PowerShell 等价：

Get-ComputerInfo         # 全量系统信息（首次可能较慢）
Get-CimInstance Win32_OperatingSystem | Select Caption, Version, BuildNumber
[System.Environment]::OSVersion.Version
$env:PROCESSOR_ARCHITECTURE    # 系统架构 x64/ARM64

图形界面工具​

工具命令用途
系统信息msinfo32硬件/软件完整清单
DirectX 诊断dxdiag显卡、显示驱动、声卡
设备管理器devmgmt.msc硬件与驱动状态
性能监视器perfmon性能计数器、可靠性记录
任务管理器taskmgr进程/性能/启动项
资源监视器resmon更细的 CPU/内存/磁盘/网络

CPU / 内存 / 硬件​

wmic cpu get name,numberofcores,numberoflogicalprocessors   :: CPU 型号与核数
wmic memorychip get capacity,manufacturer,speed             :: 内存条信息
wmic diskdrive get model,size,index                         :: 物理硬盘
wmic baseboard get product,manufacturer                     :: 主板信息
wmic bios get serialnumber                                  :: BIOS/序列号

PowerShell 等价：

Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors
Get-CimInstance Win32_PhysicalMemory | Select-Object Capacity, Speed, Manufacturer
Get-CimInstance Win32_DiskDrive | Select-Object Model, Size
Get-CimInstance Win32_BIOS | Select-Object SerialNumber
Get-CimInstance Win32_BaseBoard | Select-Object Manufacturer, Product

内存与性能监控​

Get-Counter "\Memory\Available MBytes"      # 可用内存（MB）
Get-Counter "\Processor(_Total)\% Processor Time"   # CPU 使用率
Get-Counter "\PhysicalDisk(_Total)\% Disk Time"     # 磁盘繁忙度
wmic cpu get loadpercentage                    :: CPU 占用百分比
wmic path Win32_PerfFormattedData_PerfOS_Memory get AvailableMBytes   :: 可用内存

查询性能建议看 perfmon 或直接打开任务管理器「性能」页；命令行用 typeperf 可采样落盘： typeperf "\Memory\Available MBytes" -sc 60 -si 1 -o mem.csv

已激活状态与激活信息​

slmgr /xpr                :: 查看激活状态与到期
slmgr /dlv                :: 查看详细激活信息

系统版本与 Build​

Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber
winver                    # 弹窗显示版本

环境变量与系统路径​

echo %WINDIR% %TEMP% %SYSTEMROOT%
set PATH                  :: 查看 PATH
echo %NUMBER_OF_PROCESSORS%     :: CPU 逻辑核数

常用系统目录：

位置说明
C:\Windows\Temp系统临时文件
%TEMP%当前用户临时目录
C:\ProgramData程序数据目录
C:\Users\<用户>\AppData\Local本地应用数据（常堆积大文件）
