## 使用前必读

- CMD 与 PowerShell 命令很多同名不同行为，参数区别较大，使用时注意当前终端。
- 危险命令（`rmdir /s`、`del /f`、`diskpart`、`format`）标注 ⚠️，执行前确认路径。
- 涉及系统修改的命令多数需要「以管理员身份运行」。
