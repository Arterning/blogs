# 文件与目录操作

## 浏览与切换

```bash
pwd                     # 显示当前所在目录
ls                      # 列出目录内容
ls -l                   # 详细列表（权限、属主、大小、时间）
ls -la                  # 显示全部（含隐藏文件）
ls -lh                  # 人类可读大小
ls -lt                  # 按修改时间排序
tree                    # 树状显示目录结构（需安装 tree）
cd /path                # 切换目录
cd ..                   # 返回上级目录
cd ~                    # 回到当前用户家目录
cd -                    # 回到上一个目录
```

## 创建 / 复制 / 移动 / 删除

```bash
mkdir dir               # 创建目录
mkdir -p a/b/c          # 递归创建多级目录
touch file              # 创建空文件或更新时间戳
cp src dst              # 复制
cp -r dir/ dst/         # 递归复制目录
cp -i src dst           # 覆盖前确认
mv src dst              # 移动或重命名
rm file                 # 删除文件
rm -r dir               # 递归删除目录
rm -rf dir              # 强制递归删除 ⚠️ 高危，无法找回
rm -i file              # 删除前询问
```

## 文件属性与查询

```bash
file file               # 判断文件类型
stat file               # 查看文件的详细元信息（大小、权限、时间戳）
du -sh dir              # 查看目录占用大小（详见磁盘篇）
wc -l file              # 统计行数（详见文本篇）
```

## 链接

```bash
ln -s 目标 链接名       # 创建软链接（快捷方式）
ln 目标 链接名          # 创建硬链接
readlink -f link        # 解析软链接的真实路径
ls -l                   # 链接文件显示 -> 指向目标
```

- **软链接**：类似快捷方式，可跨文件系统，删除目标则失效；对目录链接通常用软链接。
- **硬链接**：同一 inode 的多个名字，不能跨文件系统，不能链接目录。
