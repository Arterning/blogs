# 压缩归档与备份

## tar 归档

```bash
tar -czf archive.tar.gz dir/   # 打包 + gzip 压缩（最常用）
tar -cjf archive.tar.bz2 dir/  # bzip2 压缩（更小但更慢）
tar -cJf archive.tar.xz dir/   # xz 压缩（压缩率高）
tar -xzf archive.tar.gz        # 解压到当前目录
tar -xzf archive.tar.gz -C /path/   # 解压到指定目录
tar -tzf archive.tar.gz        # 查看压缩包内容不解压
tar -zxf archive.tar.gz -C /path/ file  # 只解压其中的某个文件
```

常用参数：`-c` 创建，`-x` 解压，`-t` 列表，`-z` gzip，`-j` bzip2，`-J` xz，`-f` 指定文件名，`-v` 显示进度，`-C` 指定目录。

## gzip / zstd

```bash
gzip file               # 压缩为 file.gz（原文件删除）
gunzip file.gz          # 解压
zcat file.gz            # 直接查看压缩文件内容
gzip -r /var/log        # 递归压缩目录内文件
zstd file                # 压缩（Zstandard，更快，需安装）
```

## zip / unzip

```bash
zip -r archive.zip dir/ # 压缩目录
zip -e archive.zip file # 加密压缩（会提示密码）
unzip archive.zip       # 解压到当前目录
unzip archive.zip -d /path/  # 解压到指定目录
unzip -l archive.zip    # 查看内容不解压
unzip -P pass archive.zip   # 用密码解压
```

## 7z / rar

```bash
7z x archive.7z         # 解压
7z a archive.7z dir/    # 压缩
7z l archive.7z         # 列出内容
unrar x archive.rar     # 解压 rar
```

## rsync 同步与备份（推荐）

```bash
# 本地同步
rsync -av src/ dst/            # 增量同步目录，/ 表示同步内容到 dst/
# 远程同步（走 ssh）
rsync -avz dir/ user@host:/backup/
rsync -avz user@host:/data/ ./data/
# 保留删除（镜像目录，慎用）
rsync -av --delete src/ dst/
# 排除目录
rsync -av --exclude='*.log' --exclude='node_modules/' src/ dst/
# 限速与断点
rsync -av --bwlimit=1000 -P dir/ user@host:/backup/
```

参数：`-a` 归档（保留权限时间等），`-v` 详细，`-z` 压缩，`-P` 支持断点续传与进度。目标路径末尾 `/` 决定同步层级。

> cloud `gsutil rsync` / `aws s3 sync` 同理可用于对象存储备份。

## dd 磁盘备份（高危）

```bash
dd if=/dev/sda of=/mnt/backup.img bs=4M status=progress   # 整盘镜像 ⚠️
dd if=/mnt/backup.img of=/dev/sda bs=4M status=progress   # 恢复 ⚠️ 不可选错盘
dd if=/dev/zero of=/tmp/test bs=1M count=100             # 生成 100MB 测试文件
```

> ⚠️ `dd` 输出到错误设备会直接毁掉数据，写入前务必双重确认。
