# 软件包管理

看发行版而定，主流三类：

```bash
cat /etc/os-release     # 查看发行版
```

## Debian / Ubuntu（apt）

```bash
apt update               # 更新软件源索引（必先执行）
apt upgrade              # 升级已装软件
apt install nginx        # 安装
apt install -y nginx     # 免确认安装
apt remove nginx         # 卸载（保留配置文件）
apt purge nginx          # 卸载并删除配置
apt autoremove           # 清理无用的依赖包
apt search keyword       # 搜索软件
apt show nginx           # 查看软件信息
apt list --upgradable    # 列出可升级
dpkg -i pkg.deb          # 安装本地 deb 包
dpkg -l | grep nginx     # 列出已装软件并按名过滤
dpkg -r pkg              # 卸载本地包
apt install -f           # 修复依赖问题
```

## RHEL / CentOS / Rocky（dnf/yum）

```bash
dnf install nginx        # 安装（早期系统用 yum）
dnf remove nginx
dnf update
dnf search keyword
dnf list installed
dnf groupinstall "Development Tools"   # 安装开发工具组
rpm -qa | grep nginx     # 查询已装 rpm
rpm -ivh pkg.rpm         # 安装本地 rpm
rpm -e pkg               # 卸载
rpm -qp package.rpm      # 查看 rpm 包信息
```

## 通用与新兴包管理器

```bash
snap install code        # Ubuntu snap（图形软件常用）
snap list / snap remove code
flatpak install flathub org.videolan.VLC   # Flatpak（跨发行版）
```

## 源码编译安装

```bash
# 三步曲：配置 -> 编译 -> 安装
./configure --prefix=/usr/local/soft
make
make install
# 或新版（cmake 项目）
cmake .. && make && make install
```

> 编译依赖的常见工具组：Debian 装 `build-essential`，RHEL 系列用 `dnf groupinstall "Development Tools"`。

## 配置国内源

```bash
# npm / pnpm
pnpm config set registry https://registry.npmmirror.com
npm config set registry https://registry.npmmirror.com

# pip
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# go
go env -w GOPROXY=https://goproxy.cn,direct

# docker（daemon.json 中配置）
#   registry-mirrors: ["https://docker.m.daocloud.io"]
```
