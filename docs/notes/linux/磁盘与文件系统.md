# 磁盘与文件系统

## 查看磁盘与分区

```bash
df -h                   # 查看各挂载点使用情况（人类可读）
df -i                   # 查看 inode 使用情况
lsblk                   # 树状查看磁盘与分区（推荐）
lsblk -f                # 查看文件系统类型与 UUID
blkid                   # 查看分区 UUID 与文件系统类型
fdisk -l                # 查看磁盘分区表
parted /dev/sda print   # 查看分区信息
```

符合 `sda`/`nvme0n1`/`vda` 的磁盘可通过 `lsblk` 一眼看清结构。

## 查看目录占用

```bash
du -sh /var/log         # 目录总占用
du -h --max-depth=1 /var/  # 只看一层，找出占空间的子目录
du -sh * | sort -h      # 当前目录下各文件/目录按大小排序
du -xh /                # 只统计当前文件系统，跳过挂载点
```

## 创建文件系统（格式化）

```bash
mkfs.ext4 /dev/sdb1     # 格式化为 ext4 ⚠️ 会清空数据
mkfs.xfs /dev/sdb1      # 格式化为 xfs
mkfs.vfat /dev/sdb1     # 格式化为 FAT32（U 盘）
```

## 挂载与卸载

```bash
mount /dev/sdb1 /mnt    # 挂载
mount -o ro /dev/sdb1 /mnt   # 只读挂载
umount /mnt             # 卸载
findmnt                 # 查看挂载树
findmnt /mnt            # 查看某目录挂载点
```

开机自动挂载：编辑 `/etc/fstab`，常用 `UUID=xxxx /mnt ext4 defaults 0 2`，用 UUID 更稳定。

## 查看文件系统信息与修复

```bash
stat -f /mnt            # 查看文件系统信息
fsck /dev/sdb1          # 检查修复文件系统 ⚠️ 需先卸载
fsck -y /dev/sdb1       # 自动回答 yes 修复
sync                    # 将缓存写回磁盘
```

## 交换分区

```bash
free -h                 # 查看 swap 使用
swapon --show           # 查看 swap 分区
mkswap /dev/sdb2        # 制作 swap ⚠️
swapon /dev/sdb2        # 启用 swap
swapoff /dev/sdb2       # 关闭 swap
```

## 实时 IO 查看（需安装）

```bash
iostat -x 1             # 每秒采样磁盘 IO（sysstat 包）
iotop                   # 实时查看进程 IO
```

> 磁盘空间满了但 `df` 显示不全，多半是已删除文件仍被进程占用：`lsof | grep deleted` 排查。
