## 使用前必读

- 大多数命令可通过 `man <命令>` 或 `<命令> --help` 查看详细说明。
- 危险命令（如 `rm -rf`、`dd`）请先确认路径，重要数据前建议先备份或加 `-i` 确认。
- 命令标注为 ⚠️ 时说明其对系统有破坏性，需谨慎执行。
