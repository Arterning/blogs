# Phase 1.1 基础金融概念

> 目标：建立金融世界的基本认知框架，能看懂财经新闻，理解金融机构各自的角色。

---

## 一、货币与利率

### 货币的本质

货币不只是"钱"，它是一种**信用凭证**。人民币之所以有价值，是因为中国政府承诺它可以用来清偿债务和税款。

对后端工程师的类比：货币相当于系统的"通用令牌"，所有参与者都接受它作为价值交换的媒介。

### 利率

**利率**是借钱的价格，即借款方为使用别人的钱所支付的费用。

```
借款 100 万元，年利率 5%
一年后需还款：100 万 × (1 + 5%) = 105 万元
其中 5 万元就是利息，即"借钱的价格"
```

**为什么利率是金融系统的"全局参数"**：

利率变动会影响几乎所有金融资产的价值：
- 利率上升 → 债券价格下跌（持有旧债券的人亏损）
- 利率上升 → 股票估值承压（未来现金流折现值降低）
- 利率上升 → 贷款成本上升 → 企业盈利下降

类比：利率就像系统里的一个全局配置项，改了之后所有模块都受影响。

### 几种重要利率

| 利率名称 | 谁定的 | 含义 | 例子 |
|---------|--------|------|------|
| 基准利率（政策利率） | 中央银行 | 央行向商业银行的贷款利率，是所有利率的"锚" | 中国：LPR，美国：联邦基金利率 |
| LPR（贷款市场报价利率） | 18 家银行报价 | 中国商业银行贷款的参考利率 | 1年期 LPR 约 3.1%（2024年） |
| SHIBOR | 银行间市场 | 上海银行间同业拆借利率，短期资金成本 | 类似美国的 LIBOR/SOFR |
| 国债收益率 | 市场交易形成 | 持有国债到期的年化回报率 | 10年期国债收益率约 2.3% |

### 通货膨胀

通胀是货币购买力随时间降低的现象。

```
今天 100 元能买 10 个苹果
明年通胀 5%，100 元只能买 9.5 个苹果

这意味着：今天的 100 元 > 明年的 100 元
→ 这就是"货币时间价值"的基础
```

对金融系统的意义：
- 投资回报必须跑赢通胀才算"真正赚钱"
- 央行通过调整利率来控制通胀

### 汇率

**汇率**是两种货币之间的兑换比例。

```
USD/CNY = 7.25
表示 1 美元可以兑换 7.25 人民币

如果你持有价值 1000 美元的美股：
  以美元计算：1000 美元
  以人民币计算：1000 × 7.25 = 7250 元

汇率变动 1%（7.25 → 7.18），你的人民币计价资产减少 0.97%
→ 这就是"汇率风险"
```

**直接标价法 vs 间接标价法**：
- 直接标价：USD/CNY = 7.25（1美元换多少人民币，中国常用）
- 间接标价：EUR/USD = 1.08（1欧元换多少美元，欧元常用）

## 二、金融市场分类

金融市场不是一个统一的市场，而是按交易标的分类的多个独立市场。

### 按交易标的分类

```
金融市场
├── 货币市场（Money Market）
│   ├── 期限：短期（1年以内）
│   ├── 交易品：国库券、银行承兑汇票、同业拆借
│   └── 用途：企业/银行的短期资金调剂
│
├── 资本市场（Capital Market）
│   ├── 股票市场：公司股权交易
│   └── 债券市场：中长期债权交易
│
├── 外汇市场（Forex / FX）
│   ├── 规模：全球最大金融市场，日均交易量 > 7 万亿美元
│   ├── 24小时交易（跟随全球时区）
│   └── 主要参与者：央行、商业银行、跨国公司、对冲基金
│
└── 衍生品市场（Derivatives Market）
    ├── 期货市场
    ├── 期权市场
    └── 互换市场（Swap）
```

### 场内市场 vs 场外市场（OTC）

| 维度 | 场内市场（Exchange） | 场外市场（OTC） |
|------|---------------------|----------------|
| 交易场所 | 交易所（标准化） | 双方直接协商 |
| 合约标准化 | 是 | 否，可定制 |
| 透明度 | 高（公开报价） | 低（私下协商） |
| 对手方风险 | 低（有 CCP） | 高（依赖对方信用） |
| 例子 | 上交所、纳斯达克 | 外汇市场、大部分债券 |

**对后端工程师的意义**：
- 场内交易：有标准化的 FIX 协议，接口统一
- OTC 交易：双方协商，格式多样，对接工作量大

## 三、金融机构角色

### 各机构的分工

理解这些角色，才能明白"系统是给谁用的，解决谁的问题"。

```
金融生态系统角色图：

[散户/机构投资者]
        │ 委托买卖
        ▼
[券商（Broker）]────────────────► [交易所（Exchange）]
        │                                  │ 撮合成交
        │ 清算委托                          │
        ▼                                  ▼
[清算所（CCP）] ◄──── 成交回报 ────────────┘
        │
        │ 结算指令
        ▼
[托管行（Custodian）]
        │
        │ 资金/证券划转
        ▼
[中央证券存管（CSD）]
```

### 交易所（Exchange）

**职责**：提供交易场所，撮合买卖订单。

中国主要交易所：
- **上海证券交易所（SSE）**：主板、科创板，股票代码 6xxxxx
- **深圳证券交易所（SZSE）**：主板、创业板，股票代码 0/3xxxxx
- **中国金融期货交易所（CFFEX）**：股指期货、国债期货
- **上海期货交易所（SHFE）**：商品期货（铜、黄金、原油）

### 券商（Broker/Dealer）

**职责**：作为投资者和交易所之间的中间人。

两种模式：
- **经纪商（Broker）**：代客户下单，收取佣金，不持有风险（纯中介）
- **自营商（Dealer/Principal）**：用自己的资金交易，承担风险，赚取差价

大多数券商同时做两件事，所以叫 Broker-Dealer。

### 做市商（Market Maker）

**职责**：同时提供买入和卖出报价，为市场提供流动性。

```
做市商报价：
  买入价（Bid）：149.50 元  ← 你想卖，做市商买
  卖出价（Ask）：149.60 元  ← 你想买，做市商卖

做市商的利润 = 价差（Spread）= 149.60 - 149.50 = 0.10 元/股
```

为什么需要做市商？
- 没有做市商：你要卖 AAPL，必须等另一个人同时想买，可能等很久
- 有做市商：做市商随时准备以报价成交，市场流动性好

类比：做市商就像商店，永远在"备货"，让你随时能买到或卖出商品。

### 清算所（Clearing House / CCP）

**职责**：在买卖双方之间做担保，降低对手方风险。

详见 Phase 2.3 的 CCP 章节。

### 托管行（Custodian Bank）

**职责**：安全保管客户的资产（证券和资金）。

大型机构投资者（基金、保险公司）不会自己保管几千亿的股票，而是委托托管行代为保管。

为什么需要托管行？
- 基金管理公司负责投资决策，但资产放在独立的托管行
- 如果基金公司出问题，投资者的资产在托管行是安全的
- 托管行还处理分红、拆股等企业行为

### 中央证券存管（CSD）

**职责**：统一记录证券的"最终所有权"。

中国的 CSD：
- **中国证券登记结算有限责任公司（中登）**：A 股证券的最终登记机构
- **中央国债登记结算有限责任公司（中债登）**：债券

类比：CSD 就像房产局，房子（证券）的最终产权登记在这里。

### 资产管理公司（Asset Manager）

**职责**：替客户管理和投资资产。

分类：
- **公募基金**：向公众募集，公开信息披露（如华夏基金、易方达）
- **私募基金**：向合格投资者募集，限制少（对冲基金、PE/VC）
- **保险公司**：保费作为投资资产管理
- **养老金**：替退休人员管理长期资产

## 四、账户与资金

### 账户类型

| 账户类型 | 用途 | 特点 |
|---------|------|------|
| 证券账户 | 持有和交易股票/债券 | 在中登开立，全国唯一 |
| 资金账户 | 存放交易资金 | 在券商开立，关联银行卡 |
| 融资账户 | 向券商借钱买股票 | 需要开通融资融券，有利息 |
| 融券账户 | 向券商借股票卖出 | 需要开通融资融券，看空机制 |
| 期货保证金账户 | 期货交易的保证金 | 按比例缴纳，支持高杠杆 |

### 资金的状态

```
可用余额（Available）
    可以立即用于下单

冻结余额（Frozen）
    已下单但未成交，资金被"预留"
    → 如果撤单，解冻回可用

待结算金额（Unsettled）
    已成交，但还没到结算日
    → A 股卖出后，第二天（T+1）才能取现

已结算余额（Settled）
    已完成结算，可以提现
```

```
示例：账户有 10 万元
━━━━━━━━━━━━━━━━━━━━━━━
可用余额：10 万

→ 下限价买单 5 万元（订单未成交）：
可用余额：5 万    冻结余额：5 万

→ 限价单部分成交 3 万元：
可用余额：5 万    冻结余额：2 万    待结算：3 万

→ T+1 日结算完成：
可用余额：5 万    已结算收到股票价值 3 万
━━━━━━━━━━━━━━━━━━━━━━━
```

### 融资融券（Margin Trading）

**融资**：向券商借钱买股票（做多放大）

```
自有资金 100 万，融资 100 万，总计 200 万买入股票
股票涨 10%：盈利 20 万（自有资金回报率 20%）
股票跌 10%：亏损 20 万（自有资金损失 20%）
→ 杠杆放大了收益，也放大了风险
```

**融券**：向券商借股票卖出，之后再买回归还（做空）

```
借入 100 股，以 150 元/股卖出，得 15000 元
等股价跌到 120 元，花 12000 元买回 100 股归还
→ 净赚 3000 元（做空收益）

如果股价涨到 180 元：亏损 3000 元（做空亏损）
```

## 五、央行与货币政策

理解央行行为，是理解金融市场宏观走势的基础。

### 中国人民银行（PBoC）的主要工具

| 工具 | 作用 | 影响 |
|------|------|------|
| 存款准备金率（RRR） | 规定银行必须存在央行的资金比例 | 降准 → 银行可放更多贷款 → 市场钱多 |
| LPR 调整 | 调整贷款市场报价利率 | 降息 → 贷款便宜 → 刺激消费和投资 |
| 公开市场操作（OMO） | 买卖国债控制市场利率 | 买国债→向市场注入资金（放水） |
| MLF（中期借贷便利） | 向银行提供中期资金 | 利率是 LPR 的锚定基础 |

### 为什么工程师要懂货币政策

- **降息**→ 市场资金充裕→ 股市可能上涨→ 交易量增加→ 系统压力增大
- **加息**→ 债券价格下跌→ 持有大量债券的机构可能面临亏损→ 风控触发
- **汇率贬值**→ 持有外币资产的机构盈利→ 换算为本位币的报告需要更新

懂这些，你才能理解业务方为什么突然要求"加急实现外汇敞口监控"。

## 本节小结

| 概念 | 一句话理解 |
|------|-----------|
| 利率 | 借钱的价格，是金融系统的"全局配置项" |
| 汇率 | 两种货币的兑换比例，影响跨境资产价值 |
| 通胀 | 货币购买力随时间降低，投资回报需跑赢通胀 |
| 场内市场 | 交易所，标准化，有 CCP，透明 |
| 场外市场 | 双方协商，定制化，对手方风险高 |
| 做市商 | 始终提供买卖报价，提供流动性 |
| 托管行 | 保管资产，处理企业行为 |
| 资金状态 | 可用 → 冻结（下单） → 待结算（成交） → 已结算 |
