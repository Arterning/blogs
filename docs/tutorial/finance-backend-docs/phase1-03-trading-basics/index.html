Phase 1.3 交易基础

目标：理解交易的完整流程——从投资者点击下单，到订单在交易所撮合成交的每一个环节。

一、订单类型​

订单类型决定"以什么条件成交"，是交易系统的核心输入。

市价单（Market Order）​

以当前市场最优价格立即全部成交。

场景：AAPL 当前卖价 150.10 元，你下市价买单 100 股

结果：立即以 150.10 元（甚至更高，如果 150.10 只有 50 股）成交

优缺点：

  • ✓ 保证成交，不会挂单等待
  • ✗ 不知道最终成交价（在流动性差时可能"滑点"很大）

适用场景：流动性好的大盘股、需要立即建仓/平仓

限价单（Limit Order）​

只在指定价格或更优价格成交，否则挂单等待。

场景：AAPL 当前卖价 150.10 元，你下限价买单：限价 149.50 元，100 股

结果：
  若 AAPL 价格跌到 149.50 或更低 → 成交
  若 AAPL 价格始终高于 149.50   → 挂单等待，可能永远不成交

优缺点：

  • ✓ 控制成交价格，不会以坏价格成交
  • ✗ 可能不成交，错过行情

止损单（Stop Order）​

当价格触达触发价时，自动变为市价单执行。

场景：你以 150 元持有 AAPL，设置止损单：触发价 140 元

若价格跌至 140 元 → 自动触发，以当时市价卖出（可能是 139.8 元）

用途：限制亏损（"跌到这个价格我就认输出局"）

止损限价单（Stop-Limit Order）​

触发后变为限价单而非市价单：

触发价：140 元（价格跌至此处触发）
限价：  138 元（触发后，只接受 138 元或以上的价格卖出）

风险：如果价格跳空跌至 135 元，138 元的限价可能无法成交
     你被"困住"了，损失可能更大

有效期类型​

每个订单还需要指定"有效到什么时候"：

类型英文含义
当日有效DAY当天收盘时未成交自动撤销
立即成交否则撤销IOC（Immediate Or Cancel）立即尽量成交，未成交部分撤销
全部成交否则撤销FOK（Fill Or Kill）必须全部成交，否则全部撤销
长期有效GTC（Good Till Cancelled）一直挂单直到成交或手动撤销
指定日期GTD（Good Till Date）到指定日期撤销
使用场景：
  DAY：   普通限价单，不想明天还挂着
  IOC：   算法交易，快速部分成交，减少市场冲击
  FOK：   需要一次性完整建仓，不接受部分成交
  GTC：   长期等待特定价格入场

二、交易撮合原理​

价格优先原则​

在订单簿中，更优价格的订单优先成交：

  • 买方：出价更高的订单优先（愿意出更多钱的先买到）
  • 卖方：要价更低的订单优先（愿意便宜卖的先卖出）
当前卖方订单簿：
  卖价 150.20，数量 500 股（优先级低）
  卖价 150.10，数量 300 股（优先级高）← 最先被撮合

当新的买单进来时，先撮合 150.10 的卖单

时间优先原则​

同等价格的订单，先挂单的先成交（FIFO，先进先出）：

相同卖价 150.10 的两笔订单：
  9:32:05 挂单，100 股（优先）
  9:32:09 挂单，200 股（等待）

新的买单进来，先成交 9:32:05 那笔

完整撮合流程​

步骤 1：新订单进入系统
  → 风控检查（账户状态、限额、价格偏差）

步骤 2：尝试与对手方订单撮合
  → 买单：在卖方订单簿中找价格 ≤ 买单限价的最优卖单
  → 卖单：在买方订单簿中找价格 ≥ 卖单限价的最优买单

步骤 3：撮合成交
  → 成交价格 = 挂单方的价格（maker 价格）
  → 生成成交记录
  → 更新买卖双方持仓和资金

步骤 4：剩余未成交部分
  → 限价单：进入订单簿等待
  → 市价单：如果还有剩余，继续匹配下一档

步骤 5：成交回报
  → 通知买卖双方系统（通过 FIX 协议或其他方式）

连续竞价 vs 集合竞价​

连续竞价（盘中，9:30-11:30 / 13:00-15:00）：

  • 实时撮合，一有匹配立即成交
  • 成交价格实时变化

集合竞价（A 股开盘前 9:15-9:25）：

  • 收集所有订单，最后统一以一个"最大成交量"的价格撮合
  • 这个价格就是当天的"开盘价"
集合竞价定价原理：
  找出一个价格 P，使得：
  1. 以 P 为价格，成交量最大
  2. 买方中，报价 ≥ P 的总量 ≥ 成交量
  3. 卖方中，报价 ≤ P 的总量 ≥ 成交量

例子：
  买方订单：
    150 元：100 股
    149 元：200 股
    148 元：300 股

  卖方订单：
    148 元：150 股
    149 元：250 股
    150 元：100 股

  以 149 元成交：
    愿意以 ≥ 149 买入：100+200 = 300 股
    愿意以 ≤ 149 卖出：150+250 = 400 股
    成交量：min(300, 400) = 300 股

  → 开盘价 = 149 元，成交 300 股

三、买卖价差与流动性​

Bid-Ask Spread（买卖价差）​

订单簿（Level 2 行情）：

卖方（Ask）             买方（Bid）
价格      数量          价格      数量
150.50    1000         150.30    800    ← 最优卖价 - 最优买价 = 价差 0.20 元
150.80    500          150.10    500
151.00    300          149.90    300

价差的意义：

  • 对投资者：是交易成本。你买入立刻卖出，会亏掉一个价差
  • 对做市商：是利润来源
  • 衡量流动性：价差越小，流动性越好
实际成本示例：
  你以 150.50 买入 1000 股 AAPL
  立刻以 150.30 卖出（最优买价）

  交易成本 = (150.50 - 150.30) × 1000 = 200 元
  这 200 元就是"进出一次"的隐性成本（除佣金外）

流动性（Liquidity）​

流动性指以接近市价快速完成大笔交易的能力。

流动性特征例子
高价差小、深度大、大单冲击小工商银行、茅台、AAPL
低价差大、深度浅、大单冲击大小盘股、冷门期权

市场冲击（Market Impact）：

大单会"移动市场"——你买得越多，价格被推得越高：

订单簿中 150.10 只有 300 股，你要买 1000 股：
  前 300 股：以 150.10 成交
  接下来 500 股：以 150.20 成交（下一档）
  最后 200 股：以 150.30 成交（再下一档）

平均成交价 = (300×150.10 + 500×150.20 + 200×150.30) / 1000
           = 150.19 元（高于最优价 150.10）

这 0.09 元 × 1000 股 = 90 元就是"市场冲击成本"

这也是为什么大型机构不会直接挂一个大单，而是用算法（VWAP/TWAP）分散执行。

VWAP 与 TWAP​

VWAP（Volume-Weighted Average Price，成交量加权平均价）：

目标：用接近当日 VWAP 的均价完成大单，最小化市场冲击

策略：在成交量大的时间段多执行，成交量小的时间段少执行
（因为成交量大时，大单对价格的影响相对小）

后端系统需要：
  1. 实时计算当日 VWAP
  2. 根据历史成交量分布，预测各时段应执行的比例
  3. 按计划拆分订单，分批发出

TWAP（Time-Weighted Average Price，时间加权平均价）：

目标：在一段时间内均匀执行，接近时间加权均价

策略：把大单均匀切分，每隔固定时间发一批
  → 简单易实现，不依赖成交量预测
  → 如果市场成交量分布不均，实际效果不如 VWAP

四、交割规则​

T+N 规则详解​

"交割"指成交后证券和资金真正完成转移的时间。

T = 交易日（Trade Date），即成交当天

T+0：当天成交，当天交割（实物黄金现货、部分外汇）
T+1：成交后第一个工作日完成交割（A 股股票，中国期货）
T+2：成交后第二个工作日完成交割（美股、欧洲股票、大部分外汇）

A 股的特殊规则：

A 股是"资金 T+0，证券 T+1"：
  卖出后当天资金可用（T+0）：
    9:30 卖出 AAPL，所得资金当天可以买其他股票
    
  买入后当天证券可卖（T+0，2023年起科创板、创业板实施）：
    买入后当天可以卖出（但普通 A 股历史上不可以，是"T+1"限制）

注意：
  普通 A 股买入当天不能卖出（防止过度投机）
  科创板、创业板 2023 年后允许 T+0

T+1 的影响：

今天 9:30 买入 1000 股，单价 100 元，支付 10 万元
账户变化：
  资金：可用 -10 万，待结算 -0（已扣款，资金 T+0 结算）
  证券：待交割 +1000 股（明天才能卖）

明天（T+1）：
  证券：+1000 股（可以卖出了）

交割失败​

如果在交割日无法完成交割（卖方没有足够证券 / 买方没有足够资金）：

  • Fail to Deliver（交割失败）：美国对频繁发生的机构有处罚
  • 强制买入（Buy-in）：托管行代为买入证券，费用由违约方承担
  • 回购（Repo）：短期借入证券完成交割

五、A 股市场特有规则​

A 股有很多独特的规定，如果要做 A 股后端系统，必须了解。

涨跌停板​

每日价格变动限制：
  主板：±10%
  创业板/科创板：±20%
  ST 股票（Special Treatment，有财务问题）：±5%

涨停价 = ROUND(昨收 × 1.10, 2)
跌停价 = ROUND(昨收 × 0.90, 2)

注意：涨跌停价格的精度处理
  昨收 9.97，涨停价 = 9.97 × 1.1 = 10.967
  A 股价格精度为 0.01 元，四舍五入得 10.97

集中竞价时间段​

9:15 - 9:25：开盘集合竞价（可以下单、撤单）
9:25 - 9:30：集合竞价，不接受撤单（只能下单）
9:30 - 11:30：连续竞价（上午盘）
11:30 - 13:00：午间休市
13:00 - 14:57：连续竞价（下午盘）
14:57 - 15:00：收盘集合竞价（2021年起部分市场引入）
15:00：收市

最小交易单位​

A 股：
  买入：100股的整数倍（1手 = 100股）
  卖出：可以卖出非100整数倍（如持有 150 股，可以全部卖出）

期货：
  1手 = 合约单位（各品种不同）
  沪深300期货：1手 = 指数点 × 300元（约 120 万）

ETF：
  通常 100 份为最小交易单位

两融（融资融券）​

融资买入（Margin Buying）：
  向券商借钱买股票
  利率：约 6-8% 年化
  维持担保比例：
    初始要求：130%（你的资产 / 你的借款）
    维持要求：130%（低于此触发追保通知）
    强平线：110%（低于此被强制平仓）

融券卖出（Short Selling）：
  向券商借股票卖出，之后买回归还
  适用范围：有限制，只有特定股票可以融券
  限制：T+1 归还（不能当天买回归还）

Phase 1 完成检验​

完成 Phase 1 后，你应该能够：

  • 解释为什么利率上升时债券价格会下跌

  • 看懂一条股票行情：知道 P/E、P/B、Volume、Turnover 的含义

  • 区分市价单和限价单的使用场景

  • 解释"T+1 结算"对账户资金可用状态的影响

  • 看懂以下句子不感到困惑：

    "沪深 300 期货主力合约升水 15 点，机构利用股指期货对冲多头敞口，采用 VWAP 算法分批减仓，结合期权 Delta 对冲控制 Gamma 风险。"

  • 能向业务方问出有价值的问题：

    • "这个系统处理的是场内还是场外品种？"
    • "结算是 T+1 还是 T+2？对资金账户的处理逻辑有影响"
    • "涨跌停时，风控规则是拒绝超限价的单，还是按涨跌停价成交？"
